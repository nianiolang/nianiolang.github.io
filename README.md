# nianiolang.github.io

Source for the NianioLang website and Nianio Pattern documentation.

The Nianio Pattern makes state and decisions explicit so that an application's behavior can be designed and reviewed across events. It is useful as a way to reason about software quality as well as an implementation architecture.

Start with the [pattern introduction](nianio_pattern_introduction.md), then explore the [JavaScript binding](nianio_pattern_in_nodejs.md), [HTTP game and deadlines](nianio_pattern_example_http_server.md), or [elevator walkthrough](nianio_pattern_example_elevator.md). The [JavaScript](use_case_js.md) and [C](use_case_c.md) tutorials show how to embed transition logic written in NianioLang.
